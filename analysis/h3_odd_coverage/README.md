# H3 — Operational coverage

Which regions of the operating space have been flown, and how densely.

**Deliverable: a coverage matrix, not a model.** Expressed against the ODD
representation described in [`../../docs/03-odd-representation.md`](../../docs/03-odd-representation.md),
and therefore blocked on the M0 prior-art check.

This is the artifact whose usefulness gate G5 tests. Until a practitioner says where
it would sit in their own submission, its value as safety-case evidence is a
hypothesis — see [`../../docs/05-sora-evidence-map.md`](../../docs/05-sora-evidence-map.md).
